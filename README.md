# .sai chetan Personal Universe

This is the codebase for the `.sai chetan` personal universe site. It is built with React, Vite, TailwindCSS, and Framer Motion.

## Next Steps for You

1. **Add Assets:**
   Drop your assets into the `public/assets/` directory:
   - `public/assets/stickers/krishna-swing.png`
   - `public/assets/stickers/leaf.png`
   - `public/assets/stickers/vines-top.png`
   - `public/assets/stickers/vines-side.png`
   - `public/assets/pfp/headshot.png`
   - `public/assets/pfp/meme-panel.png`
   - `public/assets/resume/Okinawa_Research_Internship_Resume_Chetan_Modern.pdf`

2. **Run Locally:**
   Make sure you have Node.js installed, then run:
   ```bash
   npm install
   npm run dev
   ```

3. **Push to GitHub:**
   ```bash
   git remote add origin https://github.com/astrochetan12-netizen/<your-repo-name>.git
   git branch -M main
   git push -u origin main
   ```
